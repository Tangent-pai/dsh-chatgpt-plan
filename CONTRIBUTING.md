# Contributing

Use issues for reproducible bugs or feature ideas. Include the plugin version, DSH Desktop version, and what you tried. For vulnerabilities, see [SECURITY.md](SECURITY.md). Keep credentials, customer data, and local profile dumps out of issues and patches.

Before opening a pull request:

1. Use Node.js 24 and run `npm ci --ignore-scripts`, then `npm test`.
2. Keep changes focused and add a regression test when behavior changes.
3. If you adapt a snippet or asset, identify its source, revision and license in the pull request. Preserve upstream notices. Contributions must be yours to share under this project's [license](LICENSE), or have a compatible license stated explicitly.

Be respectful and keep discussions on the work. Harassment, threats, and posting private data are not welcome. Report conduct problems by requesting a private channel from a maintainer.
