# Security policy

## Reporting a vulnerability

Use **Security → Report a vulnerability** on this repository if private reporting is enabled. If it is unavailable, open an issue asking the maintainers for a private contact route without including the details. Keep access tokens, device codes, account information, and private configuration out of public issues and screenshots.

Include the plugin and DSH Desktop versions, affected operating system, expected and observed behavior, and a small description that uses test data. For issues in DSH Desktop, Codex, or another dependency, contact that upstream project directly and note any effect on this plugin.

## Scope

This project is a local DSH Desktop integration. Its two sign-ins use existing OpenAI and Codex flows. The plugin does not ask for your ChatGPT password. Use the bundled and official login pages instead of passing credentials to a maintainer. Do not attach your profile or the contents of `~/.dsh-chatgpt-plan/` to reports.

## 安全问题报告

如果仓库已启用私密报告，请在 **Security → Report a vulnerability** 提交。否则可以先开一个不含漏洞细节的 Issue，请维护者告知私下联系渠道。附上插件版本、DSH Desktop 版本、系统和遇到的问题。请勿附带账号信息、令牌、设备码、完整桌面配置或个人登录目录。
